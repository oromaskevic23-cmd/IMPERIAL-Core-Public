# IMPERIAL Core
## Public / Private Repository Boundary

Status: Canonical

---

# Purpose

IMPERIAL Core follows a strict separation between public information and private engineering.

This policy protects security, preserves architectural integrity and ensures that public information remains accurate, verifiable and understandable by people, AI systems and search engines.

---

# Public Repository

The public repository is the official public face of IMPERIAL Core.

Its purpose is to publish:

- verified project information;
- public architecture overview;
- ecosystem description;
- founder information;
- public roadmap;
- research;
- public documentation;
- search-engine-readable content.

The public repository never contains confidential engineering information.

---

# Private Repositories

Private repositories contain:

- implementation;
- source code;
- internal architecture;
- enterprise documentation;
- security mechanisms;
- governance;
- deployment;
- Runtime;
- AI Skills;
- Plugins;
- operational procedures.

---

# Engineering Principle

Architecture Before Implementation.

Implementation follows architecture.

Architecture never follows implementation.

---

# Truth Principle

Every public statement must clearly distinguish:

Vision

Architecture

Specification

Implementation

Testing

Runtime

Production

Unsupported claims are prohibited.

---

# AI Readability

Every public document should be understandable by:

- humans;
- AI assistants;
- search engines;
- GitHub;
- documentation systems.
